Create a complete, polished, responsive React.js website for an AI-powered skincare and beauty platform called “Sunderta AI”.

The website should feel premium, elegant, trustworthy, modern, and feminine without looking childish. Use a soft luxury beauty aesthetic inspired by premium skincare brands.

IMPORTANT:
- Build a functional React.js website, not only static mockups.
- The final project must be downloadable and runnable as clean React code.
- Use reusable components and realistic interactions.
- Use placeholder/mock AI results where an actual AI backend is not available.
- Do not create only mobile screens. Create a complete responsive web application for desktop, tablet, and mobile.
- Preserve the core flow shown in the reference images:
  Welcome → Skin Capture → Analysis → Skin Report → AI Beauty Chat.

TECHNICAL REQUIREMENTS

Use:
- React.js
- Vite
- TypeScript if supported
- Tailwind CSS
- React Router
- Lucide React icons
- Recharts for progress and skin trend charts
- Browser camera APIs where possible
- Local mock data for reports, products, routines, and chat
- localStorage for saving scan history and onboarding state

Do not use:
- Next.js
- Backend-only functionality
- Complicated dependencies
- Unsupported proprietary components
- Hardcoded layouts that break on different screen sizes
